## 4. Открытые вопросы

1. Тестовая копия не заархивирована: через API флаг archived не применился, нужна ручная архивация в UI.
2. В запрос к KB уходит текст письма вместе с подписью. Предположение: из-за одинаковых подписей находятся случайные письма одного автора.
3. В KB два типа OCR-записей: ocr и ocr_pdf. Можно унифицировать.
4. В старых записях KB есть плейсхолдеры маскирования персональных данных.
5. PDF в исходящих письмах без «СЗ-» в имени и без темы «15/» в OCR не попадают; критерии можно расширить.
6. Sub-workflow KB: Retrieve v2 вызывается из двух узлов; другие возможные вызывающие не проверялись.

## 5. Откат

- Любой workflow: история версий n8n → rollback на версию до изменения.
- Порог: заменить «score_threshold: 0.72,» на «score_threshold: 0.65,» в узле KB: Vector Search.
- Блок источников: убрать kbLine в Validate & Render и блок KBT/kbSrc в Render PDF Message.
